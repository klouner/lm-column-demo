# Колонна LM — демо

Интерактивная 3D-модель ректификационной колонны с отбором по жидкости: режимы процесса,
датчики, автопилот, старт-стоп, защиты и учебные аварии.

Открыть: https://klouner.github.io/lm-column-demo/

Это демо-версия: подключение к контроллеру ESP32 в ней отключено, потому что браузер не пускает
публичный сайт в локальную сеть. Модель процесса — упрощённая, для наглядности.
