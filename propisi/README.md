# Прописи

Сайт-тетрадь для детей 4–10 лет: учимся писать русские буквы — печатные и прописные.
Рассчитан на планшет со стилусом (Apple Pencil), работает и на телефоне, и пальцем.

## Что внутри

- **Профили учеников** — имя, возраст, друг-аватар. От возраста зависят программа, размер букв и строгость проверки.
- **Программа**: разминка (линии и фигуры) → печатные буквы → элементы прописных букв → строчные → заглавные → слова → предложения. Буквы идут в порядке букваря.
- **Урок**: знакомство с буквой (картинка, слово, озвучка, показ написания) → обводка по контуру → по точкам → самостоятельно → слоги и слова из уже изученных букв.
- **Тетрадь**: косая линейка для прописей, широкая — для печатных букв; точка начала и порядок штрихов; ладонь не оставляет следов, когда ребёнок пишет стилусом.
- **Мягкая проверка**: за каждую букву 1–3 звезды, без «неправильно». За выученные буквы — наклейки в альбом.
- Работает без интернета после первого открытия; можно добавить на экран «Домой».

## Устройство

Статический сайт без сборки: `index.html`, `css/`, `js/`.

- `js/glyphs.js` — буквы как наборы штрихов (в порядке написания) и соединение букв в слова
- `js/curriculum.js` — разделы, уроки, слова
- `js/notebook.js` — холст тетради, письмо и проверка
- `js/app.js` — экраны

Локальный запуск: `python3 -m http.server` и открыть `http://localhost:8000`.
